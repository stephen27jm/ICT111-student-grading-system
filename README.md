STUDENT GRADING SYSTEM

1. Project Description

This is a Python console-based application developed for ICT111. It records student marks, assigns grades and generates class statistics.

2. Input – Process – Output (IPO)

Input:

- Student number
- Student name
- Student mark

Process:

- Validate student information.
- Check that marks are between 0 and 100.
- Assign grades using if, elif and else.
- Calculate class statistics.

Output:

- Student details and grades.
- Class average.
- Highest and lowest marks.
- Number of passes and failures.

3. Data Structure

A list of dictionaries is used to store multiple student records. Each dictionary contains the student's number, name, mark, grade and decision.

This makes it easy to store, access and display student information.

4. Grading Scale

Marks| Grade| Decision
80–100| A| Excellent
70–79| B| Very good
60–69| C| Good
50–59| D| Pass
0–49| F| Fail
